### ⚠️ Phát hiện: WSL giữ cache file, Windows bị đói RAM

| Thời điểm | `vmmemWSL` (phía Windows) | RAM thực dùng trong VM | Cache file trong VM | RAM khả dụng của Windows |
|---|---|---|---|---|
| Sau khi cài Temporal | **6,9 GB** | 2,15 GB | **5,5 GB** | **0,45 GB** |
| Sau `echo 3 > /proc/sys/vm/drop_caches` trong VM | 4,0 GB | 2,15 GB | 1,4 GB | **3,6 GB** |

- Cache chủ yếu do kéo image lần đầu. Giải phóng bằng tay trả lại ngay ~2,9 GB cho Windows.
- Tài liệu Microsoft ghi `autoMemoryReclaim` mặc định là `dropCache` ([Microsoft Learn](https://learn.microsoft.com/en-us/windows/wsl/wsl-config)), nhưng đo trên WSL 2.6.3 + Docker Desktop thì cache vẫn bị giữ.

### Sau khi áp dụng `.wslconfig` (cùng ngày)

Đã gỡ distro Ubuntu (sao lưu cấu hình shell sang `C:\Users\ADMIN\wsl-ubuntu-backup-2026-10-11`), tạo `%UserProfile%\.wslconfig` (`[wsl2] memory=6GB`, `[experimental] autoMemoryReclaim=dropCache`), `wsl --shutdown`, khởi động lại Docker Desktop. Cluster `foodfund` tự chạy lại, 21 pod Running.

| t (sau khởi động lại) | `vmmemWSL` | RAM khả dụng Windows | VM: dùng thực | VM: cache |
|---|---|---|---|---|
| +30 s | 5.761 MB | 1.864 MB | 2.403 MB | 3.112 MB |
| +90 s | 5.819 MB | 1.858 MB | 2.438 MB | 3.115 MB |
| +150 s | 5.832 MB | 1.911 MB | 2.463 MB | 3.116 MB |

- **`memory=6GB` có hiệu lực**: VM nhận 5,79 GiB; trần `vmmemWSL` giảm từ ~6,9 GB xuống ~5,8 GB.
- **`autoMemoryReclaim` không thu hồi cache khi cluster đang chạy** (2,5 phút). Biện pháp chủ động `drop_caches` vẫn cần — đưa thành `make reclaim`.
- RAM khả dụng của Windows ~1,9 GB lúc đo — phần còn lại do ứng dụng Windows (IDE, trình duyệt…). Nâng RAM 32 GB vẫn là phương án nếu thêm service ứng dụng làm máy chậm.

## S-7 phần 1 — Traefik `Middleware` qua `ExtensionRef`

| Phép thử | Kỳ vọng | Kết quả |
|---|---|---|
| `HTTPRoute` có filter `ExtensionRef` | `Accepted=True`, `ResolvedRefs=True` | ✅ cả hai route |
| `/webhooks/sepay`, `IPAllowList` = 203.0.113.0/24 (không chứa IP máy) | 403 | ✅ 403 |
| Đối chứng: `IPAllowList` = 172.18.0.0/16 (dải Docker) | 200 | ✅ 200; trả lại cấu hình cũ → 403 |
| `/api`, `RateLimit` average 2, burst 3; 10 request liên tiếp | Có 429 | ✅ `200 200 200 429 429 200 429 429 429 429` |
| IP mà backend thấy | — | `X-Forwarded-For: 172.18.0.1` (gateway của mạng Docker) |

→ Báo lỗi cộng đồng về `ExtensionRef` **không tái hiện** trên Traefik v3.7.14. Đúng như ADR-002 dự đoán, ở local proxy chỉ thấy IP nội bộ của Docker → **phần 2 (IP thật) phải làm trên VPS kubeadm**.
